# 내 첫 출제
## 소감
제 문제가 드디어 세상으로 나오게 되어서 기쁩니다. \
이 문제와 같이 출제되려던 **시성식 단순화** 문제는 입력 및 출력 유니코드 제한에 의해 \
수락되지 못했지만 말이죠. \
TL;DR하게 풀이 설명으로 넘어갑니다
## 풀이
이 문제는 단순 브루트포스를 사용합니다. \
|문자열| = 1일때는 단순히 한 문자열만 출력하면 됩니다. \
(k(k − 1)/ 2 ≤ |L|) 인 k의 상한을 정합니다. \
점점 줄어들면서 n = (2(L - k)) / k(k - 1) 의 값이 자연수인지 구합니다. \
식의 값이 자연수가 되는 k를 구했다면, 그 k와 n으로 문자열을 잘라 출력합니다. \
만약 k가 2까지 자연수가 아니라면 0을 출력합니다.
