# 풀이
자, 일단 문제를 보자. \
문제에서는 **동일한** 게이트를 두번 씌우면 결국 같은 결과로 돌아옴을 알 수 있다 ~~(근데이건쓰이지않는다)~~
답은 이거다. \
모든 게이트 3개에 각 상태를 정수로 인코딩한 인덱스를 넣으면 결과가 인코딩된 정수가 나오도록 하는 세 배열을 만든다. \
H = (2,3,0,1) \
Z = (0,1,3,2) \
X = (1,0,2,3) \
(단, 네 상태는 소개한 순서대로 0,1,2,3이다.) \
왼쪽 l을 처음으로 설정한 뒤 l과 r을 동일하게 만든다. 게이트를 하나 추가하면 전의 결과값에 적용시키면 된다. \
상태 저장 배열이 [0,1,2,3]이 되었을 때 카운트를 증가시킨다. \
r이 오른쪽 끝에 도달했을 때, l을 1 증가시키고, 동일하게 만든 다음. 다시 루프를 돌린다.
